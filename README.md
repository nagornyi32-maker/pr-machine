# PR MACHINE / Лига креаторов

Воксельная гача про PR-агентство: 24 оригинальных трофея, четыре тематических набора, звуки, ежедневные задания и общий недельный рейтинг.

## Игровой цикл

- 12 зачётных круток в день на профиль; обновление в 00:00 МСК.
- Новая находка сезона: +40 PR сверх очков предмета.
- Полный набор из шести предметов: +500 PR один раз за сезон.
- Три ежедневных задания: до +220 PR. Награды забираются вручную до конца дня.
- Дубликаты дают искры; за 6 / 12 / 24 искры можно выбрать отсутствующий обычный / редкий / эпический предмет.
- После 11 выпадений ниже эпического следующее гарантированно эпическое или лучше. Обмен не меняет счётчик гарантии.
- Тренировка бесплатна и не ограничена, не выдаёт предметы, искры или очки.
- Каждый понедельник в 00:00 МСК новая лига. Коллекция за всё время остаётся; очки, наборы, искры и гарантия сезона сбрасываются.

Сервер определяет выпадения, лимиты и награды. Клиент не передаёт собственный счёт. Повторные/параллельные операции защищены проверкой ревизии записи. Рейтинг сортируется по очкам сезона, затем по времени создания профиля.

## Локальный запуск

Node.js 24 LTS. Зависимости для локальной игры не нужны:

```sh
node server.mjs
```

Открыть http://localhost:3000. Данные в `data/players.json`. Старая версия профилей мигрирует автоматически; перед обновлением делайте резервную копию папки `data`. Локальное JSON-хранилище рассчитано на один процесс.

## Бесплатный публичный сайт: Cloudflare Workers + D1

Используйте Workers Free и D1 Free. Свой сервер и домен не требуются: Cloudflare выдаёт адрес `*.workers.dev` с HTTPS. Бесплатные лимиты не безграничны: [Workers](https://developers.cloudflare.com/workers/platform/pricing/) и [D1](https://developers.cloudflare.com/d1/platform/pricing/). Не включайте платный тариф для этой инструкции.

1. Создайте бесплатный аккаунт Cloudflare.
2. Установите зависимости: `npm install` (или `pnpm install --frozen-lockfile`).
3. Выполните `npx wrangler login` и подтвердите вход в своём браузере.
4. Создайте базу: `npx wrangler d1 create pr-machine`.
5. В `wrangler.jsonc` замените `REPLACE_WITH_YOUR_D1_DATABASE_ID` на возвращённый `database_id` (это идентификатор, не секрет).
6. `npm run deploy` применит миграции и опубликует сайт.

При следующих изменениях достаточно `npm run deploy`. Для локальной проверки именно Cloudflare: `npx wrangler d1 migrations apply DB --local`, затем `npm run dev:cloud`.

Исходники размещаются на GitHub, но **GitHub Pages не выполняет серверный API** этой игры. Не публикуйте `public` на Pages как готовую многопользовательскую игру. Для базы и API нужен Worker.

Токены Cloudflare, cookie, `.dev.vars`, `.env`, `data` и `.wrangler` нельзя коммитить. Они включены в `.gitignore`. Публичная база создаётся пустой; локальные профили автоматически в неё не переносятся. Для резервного копирования D1 используйте средства Cloudflare.

## Проверки

```sh
npm test
npx wrangler deploy --dry-run
```

Тесты проверяют лимиты, шансы, гарантию, награды, обмен, смену дня и недели, сохранение данных, SQL-запросы и защиту от двойного начисления. SQL-адаптер D1 проверяется на встроенной SQLite Node.js; отдельно используйте локальный Wrangler для проверки среды Workers. GitHub Actions запускает тесты при push и pull request.

## Профили и честная игра

Доступ привязан к случайной HttpOnly-cookie на год. Сервер хранит SHA-256-хеш секретного идентификатора. Имя публично, одинаковые имена разрешены. Регистрации и восстановления аккаунта нет: очистка cookie лишает доступа к профилю. Лимит 12 круток действует на профиль, а не на проверенного человека; это дружеская лига, не защищённый конкурс. Для реальных призов нужны авторизация и антибот-защита. Все игровые награды виртуальны и не имеют денежной стоимости.

Звук запускается после взаимодействия. Поддерживаются клавиатура, адаптивная вёрстка и reduced motion. Эстетика вдохновлена greative.pro; код и иллюстрации трофеев созданы специально для проекта.
